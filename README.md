## 💻 Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code (recommended)
- Git (optional)

### Installation

Clone the repository:

```bash
git clone https://github.com/ayasadiq04/aya-portfolio.git
```

Navigate to the project directory:

```bash
cd aya-portfolio
```

Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.

No additional dependencies are required.

## 📄 CV Setup

Place your CV PDF file inside the `assets/` directory and name it:

`cv-aya-sadiq.pdf`

Make sure the file path matches the download button in `index.html`.

## 🌍 Deployment

This portfolio can be deployed for free using GitHub Pages.

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and the `/ (root)` folder.
5. Click **Save**.

Portfolio URL after successful deployment:

https://ayasadiq04.github.io/aya-portfolio/
